# GeneGuard
Decode your genes. Understand your health.

An educational, open-source genetics explorer that runs entirely in the browser (single `index.html`, no build step).

## Features
Live sequence lab (GC content, reverse complement, translation, FASTA), gene explorer with chromosome map, variant lookup links (ClinVar, Ensembl, dbSNP), disease-association concepts, family history tree, offline glossary assistant, printable report.

## Run locally
Open `index.html` in a browser.

## Deploy free
GitHub Pages: Settings > Pages > Deploy from branch `main` / root. Or drag this folder onto Netlify or Vercel.

## Disclaimer
Educational use only. Not a medical device. It does not diagnose disease or predict health outcomes. Marker data in the demo is synthetic. Talk to a qualified genetic counsellor about real results.
